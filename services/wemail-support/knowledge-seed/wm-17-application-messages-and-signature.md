# 应用消息与邮件签名

## 应用消息

左侧主导航“应用消息”保存自动化规则、定时任务和智能助手主动交付的信息。消息会标明来源，报告类消息还会显示报告快照和版本，并可在应用内打开；浏览器打开的本机地址不是可跨设备分享的公网链接。

打开应用消息会标为已读，也可以手动切换已读状态。归档会把该消息从当前列表移除，但不会删除它关联的邮件、自动化规则或报告产物。页面为空时先区分：尚未产生交付结果，还是对应运行已经成功但投递没有完成；后者按产生结果的功能为主模块、应用消息为相关模块跟进。

## 邮件签名

进入“设置 → 高级设置 → 签名”。签名按当前邮箱账户保存，可以启用默认签名、填写自定义签名或恢复默认；写信时仍可逐封修改。关闭“使用签名”后，发送邮件不会自动添加签名或 `Sent with Wemail`。

切换邮箱后看到不同签名是账户隔离，不是签名丢失。同一邮箱保存后新建邮件仍未采用、关闭后仍自动添加，或恢复默认没有生效时，记录操作前后状态并按签名设置异常跟进；不要索取完整业务邮件正文。
