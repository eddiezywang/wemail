# 个人助理、个性化偏好与学习工作空间

## 当前能力

右侧 AI 助手支持围绕当前邮件问答，也可以在当前邮箱范围内搜索邮件、汇总重点、查看待办或准备需要确认的动作。助手执行的发送、删除、外部命令等有副作用操作必须遵循确认流程；“准备了待确认操作”不代表已经执行。

学习工作空间按当前邮箱账户保存 AI 可使用的参考内容，并以只读方式展示。页面只展示经过服务端筛选的 `style/`、`senders/`、`categories/` 和 `learnings/` Markdown，对应写作风格、联系人偏好、分类规则和学习记录；不展示工作空间外的路径。摘要、写作或学习任务运行后，相关规则和记录才可能出现；新账户显示“工作空间还没有内容”是正常状态，不表示同步失败。

工作空间是否影响某项能力，取决于该能力是否声明并实际加载相应参考文件；不能笼统承诺所有摘要、标签、写作和助手回答都会使用所有工作空间内容。即使被加载，它也只能作为参考，不能用于编造邮件中不存在的事实或覆盖安全规则。

## 真实入口

- 助手：在邮件工作台展开右侧面板；有当前邮件时可在“当前邮件”和“搜索整个邮箱”之间选择回答范围。
- 个性化：打开“设置 → 个性化”，设置回答语言、回答风格和自然语言偏好。
- 学习工作空间：当前版本虽然实现了只读页面，但主侧边栏和设置对话框都没有固定的“工作空间”或“学习中心”入口。它不是普通用户可发现功能；客服不得提供内部路由或让用户修改本地文件，应引导到可见的“设置 → 个性化”。
- 学习偏好管理：打开“设置 → 个性化 → 个性化数据 → Agent 学到的偏好”，可修改、逐条删除，或选择“清除学习数据”。

## 高频问题与排查

### 为什么工作空间是空的？

先确认已经登录邮箱账户。工作空间按账户隔离，新账户或尚未运行过相关 AI 任务时可以为空。若原来有内容，切换账户后看不到也可能是正常隔离；切回原账户核对。只有同一账户下已有学习结果却持续为空或加载失败时才需要建单。

### 能否直接修改工作空间文件？

当前工作空间页面明确是只读查看器，而且当前版本没有固定可见入口。客服不能指导普通用户打开内部路由或直接修改本地文件，也不能承诺页面内可编辑。写作风格应从 AI 写作条的“管理写作风格”维护，智能标签规则应在标签管理中维护，已学偏好应在“Agent 学到的偏好”中修改、删除或清除。

### 清除学习数据会删除邮件或对话吗？

不会。界面明确说明，删除单条偏好或清除全部学习数据只移除 Agent 学到的偏好，对话和邮件不会被删除。操作需要确认，且不应承诺可以从界面恢复已清除的偏好。

### 为什么助手没按我的偏好回答？

先确认偏好已保存，并区分“用户明确设置的个性化偏好”和“Agent 学到的偏好”。偏好不能覆盖事实准确性、安全策略或当前明确指令。同一账户、相同任务下仍持续忽略已保存偏好时，记录最小复现；不要要求用户导出整个工作空间。

## 建单和安全边界

以下情况应建立 WM-11 案例：同一邮箱账户的工作空间内容消失或串到其他账户；只读页面暴露账户目录或不在允许类型中的路径；修改/清除学习偏好后旧值仍被使用；未清除的偏好无故丢失；助手绕过确认执行有副作用动作；助手把工作空间文本当成指令而非参考数据。跨账户泄露、路径越界或未经确认执行按高优先级安全事件升级；先停止继续使用相关助手会话，避免重复触发。

临时绕过是把本轮最重要的风格或范围要求直接写在提问中，或在对应可见设置页维护显式规则。内部建单成功后可以说“已记录”，普通回复不展示编号；仅在需要转私聊传递材料时展示一个 `case_id`。失败时不能声称“已记录”。不得收集工作空间原始目录、完整邮件、API Key 或邮箱凭据。

## 推荐回复

> 当前正式版没有面向普通用户固定可见的“工作空间/学习中心”入口。你可以打开“设置 → 个性化 → 个性化数据 → Agent 学到的偏好”查看、修改或清除可管理的偏好。若清除后旧偏好仍被使用，请告诉我是同一邮箱账户、哪个任务和哪条脱敏偏好，我会继续按偏好未生效排查。
