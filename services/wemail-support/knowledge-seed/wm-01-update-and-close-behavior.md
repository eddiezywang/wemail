# 检查更新、安装更新与关闭窗口行为

## 操作入口

打开左下角“设置”，在设置分类中选择“关于”，进入页面里的“软件更新”。这里会显示当前版本和以下可区分状态：尚未检查、正在检查、已是最新、发现新版本、正在下载、已下载并通过验证、等待退出安装或失败。发现新版本后，需要点击“立即更新”才会下载；下载并验证完成后，才会出现“立即重启安装”和“退出时安装”。若“检查更新”不可点击且页面显示“此构建未启用自动更新”，当前构建不支持从这里更新。

## 关闭窗口为什么还在运行

WeMail 的关闭按钮有两种行为：

- “最小化到系统托盘”：窗口关闭后仍在后台同步邮件；
- “退出 WeMail”：停止后台同步并完全退出。

可以在“设置 → 高级设置 → 用户偏好 → 关闭窗口时”修改。选择了“退出时安装”后，仅关闭到托盘不会触发安装，必须完全退出 WeMail，或点击“立即重启安装”。

## 更新失败的排查顺序

1. “当前网络不可用”：先恢复普通网络，再点击“检查更新”；
2. “更新服务器暂时不可用”：保留当前版本和发生时间，稍后只重试一次；
3. “更新信息无效”或“更新安全验证失败”：不要继续下载、不要绕过验证，直接建立支持案例；
4. “更新下载失败”：在当前页面点击“重试”；
5. “磁盘空间不足”：清理安装盘空间后重试；
6. “安装程序未能启动”：完全退出并重新打开 WeMail，再到“设置 → 关于”检查更新一次。

若相同步骤连续失败、出现安全/元数据验证错误，或更新后无法启动，建立 WM-01 案例。案例写明预期/实际、当前版本、目标版本、用户可见状态、发生时间、是否关闭到托盘、一次重试结果和临时处理；可进入主界面时再从“设置 → 高级设置 → 诊断 → 导出诊断包”取得诊断文件。安全验证失败按高优先级处理，其他按影响范围定级。

内部建单成功后可以说“已记录”，普通回复不展示编号；仅在需要转私聊传递材料时展示一个真实 `case_id`。没有工具回执时不得说“已记录”。不要索取数据库、邮箱凭据、API Key 或邮件内容。
