# 外观、通知、数据隐私与本地诊断

## 外观与主题

当前产品是 Windows 桌面版 WeMail。进入“设置 → 高级设置 → 外观”，可以选择：

- “跟随系统”：随 Windows 的浅色或深色偏好切换；
- “浅色”；
- “深色”。

当前只能在这三种显示方式中选择，不支持用户任意指定主题色、背景色或导入自定义配色。主题选择会保存在本机并持续生效；应用主题不会套用到邮件正文，邮件正文保持独立的可读显示。

用户认为现有配色不好看时，先承认这会影响使用体验，再直接告知现有选项和入口。用户已经明确希望改变配色时，这本身就是有效产品诉求，确认当前不支持任意自定义后直接记录，不再问“是否需要记录”；可以在记录后追加一个可选问题，了解最想调整的区域或颜色。不要追问桌面端、网页端还是手机端，也不能把“暂不支持自定义配色”误答成完全不能切换浅色或深色。

标准答法：

> 明白，现有配色会直接影响你的使用体验。目前可以在“设置 → 高级设置 → 外观”切换“跟随系统、浅色、深色”，但还不能任意自定义主色或各区域配色。你提的自定义配色需求已经记录为产品改进建议；如果愿意补充，最想调整的是导航、邮件列表还是阅读区？

## 通知设置

进入“设置 → 高级设置 → 通知”。可分别控制：

- “需要处理的事项”：Agent 等待确认、邮箱登录失效或任务失败且需要介入时提醒；
- “新邮件”：所有实时收到的新邮件使用 Windows 通知，关闭后仍保留任务栏角标；
- “通知声音”：只控制是否播放系统提示音。

锁屏通知内容可以选择“仅显示新邮件数量”“显示发件人，不显示主题”或“显示发件人和主题”。通知不会显示正文、附件内容或账户凭据。企业环境优先建议“仅显示新邮件数量”。

若收不到通知，先确认对应 WeMail 开关已打开，再点击“打开 Windows 通知设置”确认 Windows 没有禁用 WeMail 通知、勿扰模式没有拦截。只有新邮件没有通知时，再看任务栏角标和邮件到达时间：角标也没变化时先核实实时同步；角标已变化但没有 Windows 弹窗时再排查通知权限。不能把邮件尚未同步误判为通知模块故障。

## 使用数据和隐私

进入“设置 → 高级设置 → 诊断”可开关“使用数据”。当前界面说明会用于产品与稳定性分析的内容包括操作系统用户名、安装标识、应用版本和功能行为；不会上报邮件内容、主题、联系人、搜索词或 AI 输入输出。

客服回答“所有数据都绝不会离开本机”是不准确的：邮箱连接、AI 请求和用户启用的外部 Bot 各有自己的数据链路；“AI 用量记录仅保存在本机”和“诊断使用数据不上报邮件内容”也不能扩大解释为整个产品完全离线。涉及具体隐私问题时，应先确认用户问的是使用数据、AI、邮箱、Bot 还是诊断包，再分别说明。

## 诊断包与调试日志

进入“设置 → 高级设置 → 诊断”可查看运行平台和 Electron 版本。“导出本地诊断包”会先生成经过脱敏的临时诊断文件，内容取各个可读取应用日志文件最近最多 500 行的脱敏结果，且不会自动上传。WeMail 管理的临时 JSON 按 7 天保留策略清理；用户通过保存对话框另存的 ZIP 副本不受该自动清理保证，发送后应由用户自行删除。

“调试日志”普通模式只保留关键运行结果和错误；开启后记录更详细的诊断信息，并在最多 30 分钟后自动关闭。日志层会按敏感字段名深度脱敏，但脱敏不是“绝不包含个人信息”的保证：自由文本仍可能残留用户名、本机路径、账户标识、时间、运行环境或企业内部信息。复现一次后立即关闭，导出前仍应确认文件中没有业务敏感片段，并将整个 ZIP 按敏感资料处理。

支持人员已确认需要进一步定位时，优先建议用户把诊断 ZIP 发送到与 WeMail 助手的一对一会话。只有助手明确要求从群聊转私聊传包时，才以脱敏摘要创建一次交接案例并在群里返回 `case_id`；普通咨询、同一问题的追问和文件补充不新增编号。私聊侧使用网关注入的企微 User ID 校验案例归属并恢复案件摘要，不合并群聊与私聊的原始消息。

用户选择直接在群聊上传诊断包时，助手不拦截、不删除，也不要求重新私聊发送，应直接安全解包、二次脱敏并分析。群聊回复只给故障时间、事件类型、错误码和判断依据的最小结论，不复述日志中的用户名、路径、账户标识或完整内容。完成后删除机器人侧收到的临时缓存；诊断包不得原样转发给其他用户或写入知识库。若助手没有实际读取成功，必须说明失败原因，不能声称“已分析”。

## 何时建单

满足任一项应建单：WeMail 和 Windows 通知均已开启且实时新邮件稳定无通知；选择的锁屏隐私级别未生效；关闭使用数据后状态无法保存；诊断包导出失败；诊断包出现疑似未脱敏的邮件正文、密码、令牌或 API Key；调试日志超过 30 分钟仍未自动关闭。

案例归 WM-17。建议收集：WeMail 版本、Windows 版本、具体通知类型、WeMail 和 Windows 开关状态、发生时间、任务栏角标是否出现、勿扰模式状态、诊断导出结果和脱敏后的错误文案。案例中不要直接粘贴完整诊断包内容或本机路径；疑似敏感数据泄露时只描述字段类型、出现位置和是否已停止分享，并按高优先级安全事件处理。

写清预期、实际、影响范围和临时处理。内部建单成功后可以说“已记录”，但不展示编号；仅在需要转私聊传包时展示一次真实 `case_id`。工具失败只能说“暂未记录成功”。用户在群聊发送诊断包时正常接收分析，同时提醒其群聊公开范围风险，不强制撤回或重复发送。

## 标准答法

用户问“导出的诊断包会不会自动上传、7 天后是不是电脑里的副本都会消失”时，先回答：

> 不会自动上传。WeMail 管理的临时诊断文件按 7 天策略清理，但你通过保存对话框另存的 ZIP 副本不会由 WeMail 保证自动删除；提供给支持人员前请先确认接收对象，处理完成后自行删除副本。

用户在群里问“能不能把诊断包直接发这里”时，直接回答：

> 可以直接发，我会在当前群里分析；不过诊断包虽然经过脱敏，仍可能包含个人或企业环境信息，更建议私聊发送。如果你选择私聊，我会只在转场时给你一个案例编号用于续接当前问题。
