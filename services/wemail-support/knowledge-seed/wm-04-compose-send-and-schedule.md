# 写信、回复、草稿、附件与定时发送

## 实际入口

- 新邮件：点击左侧“写邮件”；
- 回复/转发：打开目标邮件，使用邮件详情中的“回复全部”或“转发”等按钮；具体按钮可能位于发件人操作区或更多菜单；
- 抄送/密送：在写信窗口的收件人行点击“CC / BCC”；
- 保存草稿：点击写信窗口底部“保存草稿”；有未保存修改时关闭窗口，会出现“保存草稿并关闭 / 放弃修改 / 继续编辑”；
- 定时发送：点击发送按钮旁的下拉箭头，选择未来时间；安排成功后可从左侧“定时发送”查看“等待发送 / 已发送 / 发送失败 / 已取消”状态。

回复会自动带入发件人和 `Re:` 主题；回复全部会排除当前邮箱并去重收件人；转发会生成 `Fwd:` 主题。原邮件有附件时，转发正文只会提示用户确认是否需要重新添加，不能向用户承诺原附件已自动随转发带上。

## 附件限制

当前写信窗口支持多选附件：单个附件不能超过 10 MB，全部附件合计不能超过 25 MB。超过限制时，应让用户减少文件、压缩文件或改用合规的文件共享方式；不要声称可以绕过客户端限制。

## 发送失败的排查顺序

1. 确认至少有一个有效收件人；主题不是当前发送的必填项，空主题会显示为“(无主题)”，客服不得把空主题误判成发送阻断；
2. 检查收件人地址是否完整，尤其是手工粘贴的多个地址；
3. 检查附件是否超过单个或合计限制；
4. 确认网络可用、当前邮箱连接未失效；
5. 如果收信正常但所有发信都失败，按 SMTP 服务器、端口、加密方式、发信权限或 SMTP 凭据方向排查。登录成功只代表 IMAP 校验通过，不能证明 SMTP 一定可用；
6. 失败或超时后不要连续点击发送。先确认“已发送”中是否已有该邮件；若结果未知，先保留草稿并查明状态，避免重复发送。

可临时先“保存草稿”，待网络或配置恢复后从草稿重新发送。定时发送必须选择未来时间；“取消发送”会停止待发送任务并保留记录，“删除”会永久移除记录，待发送记录被删除后邮件也不会发送，两者不能混用。

同一草稿连续失败、所有收件人均失败、界面提示成功但“已发送”中没有记录、定时邮件到点未发送或出现可能重复发送时，应建立 WM-04 案例。案例写明优先级、预期/实际和临时处理。工具成功后可以说“已记录”，普通回复不展示编号；仅在需要转私聊传递材料时展示一个 `case_id`。邮箱地址只保留脱敏域名信息，不收集正文、附件、密码或完整收件人名单。

通过智能助手提出的发信或定时发信属于外部副作用，必须展示收件人、主题、正文和附件摘要的邮件预览并取得明确确认后才能执行；同名联系人未消歧时不得发送。生成草稿不等于已经发送，执行结果未知时也不得自动重试。
