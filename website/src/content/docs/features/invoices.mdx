## 工作方式

WeMail 根据邮件主题、正文上下文、附件文件名与类型发现发票候选项。候选附件可以显示发票号码、销售方、金额、费用类型和平台处理状态等信息。

## 状态说明

- **未上传**：尚未在平台中完成上传。
- **上传失败**：最近一次上传没有成功，可查看错误并重试。
- **已上传**：当前附件已经完成上传。
- **本人已关联**：发票已关联到当前用户。
- **已被他人关联**：发票已被其他人员关联，不应重复处理。
- **状态未知**：暂时无法确认平台状态，可稍后刷新。

## 上传流程

1. 打开发票邮件并检查附件。
2. 刷新平台状态，避免重复上传。
3. 核对金额、抬头和发票号码。
4. 明确发起或确认上传。
5. 查看最终状态；失败时保留原附件并按提示重试。
