WeMail MCP 是可选功能，默认关闭，只监听 `127.0.0.1`。

## 启用和连接

1. 打开 **设置 → MCP**，启用本地 MCP。
2. 保持默认端口 `43129`，除非它与其他本地服务冲突。
3. 启用后由 WeMail 准备连接凭据；选择客户端格式并复制连接配置。
4. 把配置加入兼容的本地 MCP 客户端，然后重载客户端。

```json
{
  "wemail-mail-mcp": {
    "type": "streamablehttp",
    "url": "http://127.0.0.1:43129/mcp",
    "headers": {
      "Authorization": "Bearer <local-credential>"
    }
  }
}
```

## 能力边界

读取类工具返回账号范围内的有界数据。列表和搜索优先返回信封信息；读取指定邮件或会话时才加载目标内容和附件元数据。

持有凭据的客户端可以发送、移动和删除邮件，包括永久删除；WeMail 不会为这些 MCP 写操作额外弹出确认。部分操作先准备再由客户端提交，提交前不代表已经执行。只向可信客户端提供凭据，并在客户端侧审查操作。

发信操作提交成功表示邮件已进入本地发件队列，不代表 SMTP 发送成功或收件人已收到邮件。需要确认时，请检查已发送邮件并通过其他渠道向收件人确认。

当前 MCP 草稿保存和发信不支持附件；包含附件的相关请求会被拒绝，不会自动去除附件后继续。

## Token 安全

把连接凭据当作邮箱密码处理。不要粘贴到聊天、日志、截图、源码或远程 MCP 服务。怀疑泄露时立即重置；不再使用时关闭 MCP 并终止相关会话。

取消请求、终止会话或关闭 MCP 不保证已经派发的邮件操作被撤回。若结果未知或批量操作中断，请先检查邮箱状态，再决定是否重新操作。

尚未提交的操作不会因创建它的会话结束而自动取消。同一账户的其他已认证客户端如果知道操作 ID，仍可查询该操作；在它过期或进入终态前，也可取消或提交。
