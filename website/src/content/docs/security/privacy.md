## 本地优先

WeMail 桌面运行时在本机保存邮箱工作数据、队列状态和应用配置。它不等于“所有处理永远不离开设备”：当你配置外部邮箱或 AI 服务时，相应请求仍会发送给你选择的服务商。

遥测在未配置端点时关闭。运行时环境变量或下游安装包中的 `build/telemetry-config.json` 都可能提供端点；安装包中的配置和令牌可以被接收者读取。启用后，遥测包含本机操作系统用户名、安装标识、应用及平台版本和经过校验的事件元数据，发送到配置的端点。

本地应用 API 绑定回环地址，带 Origin 的浏览器请求仅允许应用配置的渲染页面来源；但无 Origin 的请求仍可访问，当前没有隔离同机其他进程的逐客户端身份验证。请在可信的操作系统账户和本机软件环境中使用。

打开邮件时，远程图片可能由本机代理自动请求。图片服务器可能获知你的网络地址和图片 URL 中的标识；应用只过滤部分明显的追踪像素，不能保证阻止所有邮件追踪。代理在内存中保留有限数量的图片，响应允许客户端私有缓存最长 24 小时；浏览器可能按自身缓存策略把响应和 URL 写入磁盘。

## 邮箱与 AI 凭据

- 使用服务商推荐的应用专用密码或授权方式。
- 不要把 `.env`、本地设置、真实凭据或审计日志提交到源码。
- 定期检查不再使用的账号、模型密钥和连接。

## MCP

- 默认关闭并仅绑定回环地址。
- 连接凭据由应用管理，应像邮箱密码一样保护。
- 读取结果受账号与大小边界限制。
- 持有凭据的客户端可直接执行发送、移动和删除等写操作，WeMail 不再弹出确认。

## 文档与截图

编写示例和截图时，请使用虚构数据并检查是否包含敏感信息。提交问题前请清除地址、主题、正文、附件、账号标识、Token 和本地路径中的敏感信息。
