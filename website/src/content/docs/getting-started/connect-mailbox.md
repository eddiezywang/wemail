---
title: 连接邮箱
description: 使用 IMAP 与 SMTP 将邮箱连接到 WeMail。
---

WeMail 使用 IMAP 同步邮件，使用 SMTP 发送邮件。输入邮箱地址后，WeMail 会读取 `@` 后的邮箱域名并选择匹配的服务商预设；如果没有匹配的预设，请选择自定义 IMAP/SMTP 并向邮箱管理员确认参数。

## 准备信息

- 邮箱地址和显示名称。
- 登录用户名，通常是完整邮箱地址，而不是只填写 `@` 前的部分。
- IMAP 主机、端口与加密方式。
- SMTP 主机、端口与加密方式。
- 邮箱密码、应用专用密码或服务商授权码。

## 服务商预设

下表与 WeMail 当前内置的邮箱预设一致。

| 服务商 / 域名 | IMAP | SMTP | 加密与认证说明 |
| --- | --- | --- | --- |
| 163 邮箱 (`163.com`) | `imap.163.com:993`，SSL/TLS | `smtp.163.com:465`，SSL/TLS | 先开启 IMAP/SMTP，使用 16 位授权码，不要使用登录密码。 |
| 126 邮箱 (`126.com`) | `imap.126.com:993`，SSL/TLS | `smtp.126.com:465`，SSL/TLS | 先开启 IMAP/SMTP，并使用邮箱生成的授权码。 |
| QQ / Foxmail (`qq.com` / `foxmail.com`) | `imap.qq.com:993`，SSL/TLS | `smtp.qq.com:465`，SSL/TLS | 开启 IMAP/SMTP 后使用授权码。 |
| Gmail (`gmail.com` / `googlemail.com`) | `imap.gmail.com:993`，SSL/TLS | `smtp.gmail.com:465`，SSL/TLS | 开启两步验证时，使用应用专用密码。 |
| Outlook / Hotmail / Live (`outlook.com` / `hotmail.com` / `live.com`) | `outlook.office365.com:993`，SSL/TLS | `smtp.office365.com:587`，STARTTLS | 账号或组织策略可能要求应用专用密码或现代认证设置。 |
| iCloud (`icloud.com` / `me.com` / `mac.com`) | `imap.mail.me.com:993`，SSL/TLS | `smtp.mail.me.com:587`，STARTTLS | 使用 Apple ID 生成的应用专用密码。 |
| 自定义 IMAP/SMTP | 用户填写，默认 `993`，SSL/TLS | 用户填写，默认 `465`，SSL/TLS | 根据管理员提供的配置选择 SSL/TLS 或 STARTTLS，并核对端口。 |

端口 `993` 和 `465` 的预设使用连接建立即加密的 SSL/TLS。端口 `587` 的预设使用 STARTTLS：先建立连接，再升级为 TLS。自定义服务器不一定采用默认值，必须同时核对端口和加密方式。

## 授权码与应用专用密码

- 服务商授权码是为 IMAP/SMTP 客户端生成的独立凭据，不是网页登录所用的登录密码。
- 开启两步验证后，Gmail、iCloud 或其他服务商可能要求应用专用密码。
- 企业或组织邮箱还可能受管理员策略、现代认证或客户端访问限制约束。
- 优先使用服务商提供的授权码或应用专用密码，避免把主账号密码交给第三方客户端。

## 连接步骤

1. 打开账号设置并选择添加邮箱。
2. 输入邮箱地址，让 WeMail 按邮箱域名选择预设；不匹配时选择自定义 IMAP/SMTP。
3. 确认用户名、主机、端口和加密方式，并填写授权码、应用专用密码或组织提供的凭据。
4. 保存后等待首次同步完成。
5. 发送一封测试邮件，确认收取与发送均可用。

## 连接失败排查

- **用户名或凭据错误：** 确认用户名使用完整邮箱地址，并重新生成授权码或应用专用密码。
- **端口与加密方式不匹配：** `993` / `465` 通常使用 SSL/TLS，`587` 使用 STARTTLS；自定义配置以管理员说明为准。
- **服务未开启：** 在服务商设置中开启 IMAP/SMTP，部分服务商开启后才允许生成授权码。
- **网络被拦截：** 检查系统防火墙、公司网络、VPN 或代理是否阻止 IMAP/SMTP 端口。
- **服务商安全拦截：** 查看账号安全通知、异常登录提示、组织安全策略和第三方客户端限制。

:::danger
不要把真实邮箱密码、授权码、服务器日志或完整配置截图粘贴到问题反馈、AI 对话或代码仓库中。分享日志或截图前请移除邮箱地址、服务器凭据和可识别账号的信息。
:::

如果仍然无法连接，请记录不含敏感信息的错误类型和发生阶段，再联系邮箱服务商或组织管理员核对客户端访问策略。
