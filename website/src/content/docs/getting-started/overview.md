WeMail 是面向 Windows 的本地优先智能邮件客户端。它连接你的 IMAP/SMTP 邮箱，在本地保存工作数据，并在你配置 AI 服务后提供摘要、行动项、智能草稿、智能标签和 Agent 能力。

## 核心能力

- 在一个桌面工作台中阅读、搜索、撰写和管理邮件。
- 对单封邮件或会话生成摘要，并提取待处理事项。
- 识别发票邮件，显示附件处理与平台状态。
- 通过仅监听本机回环地址的 MCP 服务连接兼容 AI 客户端。
- 对发送、移动、删除等高风险操作保留确认边界。
