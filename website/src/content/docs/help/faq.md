## 不配置 AI 可以使用 WeMail 吗？

可以。基础邮箱连接、同步、阅读和撰写不要求配置 AI；摘要、智能标签、草稿和 Agent 等能力需要兼容的 AI 服务。

## WeMail 会自动发送 AI 草稿吗？

生成草稿不等于发送。Agent 发起发送和其他高风险操作时需要用户确认；持有 MCP 凭据的客户端则可以直接发信，无需 WeMail 再次确认。请只向可信的 MCP 客户端提供凭据。

## 可以发送附件吗？

当前发件队列和草稿存储尚不支持保存附件内容。含附件的发信、定时发信或草稿保存请求会被拒绝；请使用其他方式发送附件。邮件进入发件队列也不代表收件人已经收到。

## 文档中的动画是真实应用录像吗？

不是。它们是使用虚构内容制作的 HTML/CSS 界面示意，不包含真实邮箱、邮件内容、Token 或账号信息；实际界面和功能以当前版本为准。

## MCP 可以从其他设备访问吗？

默认不可以。WeMail MCP 只监听本机回环地址 `127.0.0.1`，用于当前设备上的兼容客户端。

## 如何获取原始 Markdown？

把文档页面的源路径放到 `/raw/` 下，并保留 `.md` 或 `.mdx` 扩展名。例如：`/raw/features/mcp.mdx`。

## 卸载会自动安全擦除数据吗？

不要作此假设。设备移交或报废时，应先退出账号，并使用组织认可的数据清理流程处理本地数据。
