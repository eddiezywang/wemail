# 数据选择

只负责定义“读取哪些邮件或附件”，不执行分析、生成产物或发送消息。

1. 明确范围：当前邮件、当前会话、某个日历日、滚动窗口或上次调度窗口。
2. 将主题、发件人、标签、正文特征、附件类型等条件写入 `DataSelectionSpec.filters`。
3. 必须给出 `maxMessages`，按需限制附件数量和总字节数；这只是选择规则的资源保护，不是“最近 7 天最多取 N 封”的业务数据边界。
4. “今天”必须绑定账户时区；自动化中优先使用 `previous_schedule_window` 防止漏数或重数。
5. 模糊语义先生成最多 10 封的脱敏匹配样本，让用户用自然语言确认或修订；样本上限不代表最终分析只允许这些邮件。
6. 输出只包含选择规则与样本来源标识，禁止把样本正文固化到规则。

输出类型为 `data-selection`。参考 [匹配规则](references/matching.md)。
