# Acceptance Plan

状态：验收进行中，已获授权执行类型检查、测试、生产桌面构建及隔离运行验收。生产构建和模拟邮箱桌面交互已通过；真实 IMAP、完整故障矩阵及资源/延迟采样仍待完成。已运行结果见 `verification.md`，以下目标不代表已全部通过。

## Evidence and Targets

- 使用固定时钟和可控 provider/Writer 的确定性测试证明调度边界；不得用真实网络抖动替代逻辑断言。
- 补偿检查在活动账户上每 60 秒到期；时间含义是检查意图到期，不承诺网络故障下 60 秒内收到邮件。
- 在依赖可用、无服务端限流且当前操作已结束的测试中，手动/实时意图应在 1 秒内派发，不随正文队列深度增长。
- 阻塞 IMAP 操作默认 30 秒进入回收；活动同步无命令完成/落库进度 60 秒进入恢复；空闲无新邮件不触发超时。
- 页面最多 50 封；UID 搜索、消息暂存和待提交页均有界。6,000 封与更大 fixture 对比时，活动页和 session 数量不随总邮件数增长。
- 真实 Windows 邮箱记录各阶段 p50/p95/max。健康连接下，目标为观察到 IDLE 或手动触发至首批列表可见 p95 ≤ 5 秒；这是待实测目标，不是当前保证。超标须报告各阶段与 fixture，不能仅报告总平均值。
- 完整性以远端测试邮箱 UID/消息集合与本地集合比对，要求配置覆盖范围内零遗漏、无重复本地身份或业务副作用。

## Scenario Matrix

| 场景 | 注入方式 | 必须观察的结果 |
| --- | --- | --- |
| 启动离线后恢复 | 登录/查询连续失败超过六次，再恢复网络 | 不重启、不点击刷新即可补拉并恢复监听 |
| 空闲线程退出 | 无待办 metadata 时退出账户 Worker | 新 generation 从最新检查点恢复，监听重新建立 |
| 同步线程有心跳但请求卡住 | provider 请求不返回 | 到期回收实际 session/Worker，旧结果不污染新进度 |
| IDLE 事件丢失 | 投递邮件但不发送 exists | 补偿检查发现邮件，无需再投递一封 |
| 查询结束时再次到信 | 搜索返回后、重挂监听前投递 | pending 或补偿检查补回，不永久遗漏 |
| 多入口同时刷新 | manual、IDLE、compensation 同时触发 | 单 active、至多一份 pending，无重复 session |
| 休眠后恢复 | 跨过多个检查期限 | 只立即安排一次补拉，无 tick 风暴 |
| 正文积压 | 50 封慢正文排队时触发刷新 | 当前操作结束后优先派发元数据，不等队列排空 |
| 后台长期暂停 | governor 持续暂停历史 | 核心小页仍有进度，历史/预取仍受限 |
| 离线新增 6,000 封 | 包含乱序日期、稀疏 UID | 分页完整落库，游标不跳过早期结果 |
| 事务前后退出 | 提交前失败、提交后 ACK 丢失分别注入 | 前者游标不前移，后者安全重放且不重复自动化 |
| FETCH 缺项 | 一次返回缺 UID，分别模拟删除/临时失败 | 确认缺项后才推进，临时失败不被当作删除 |
| 其他文件夹到信 | INBOX 不变，仅规则目录到信 | 各自游标增量发现，无反复按 INBOX 日期扫描 |
| 慢文件夹 | 阻塞一个其他目录页 | INBOX 已完成页先可见，其他目录仍能公平续跑 |
| UIDVALIDITY 变化 | 更改单目录 generation 并重放旧页 | 只重建该目录，旧页被拒绝，历史覆盖单独记录 |
| 已有缺口修复 | 预置最大游标及范围内未入库邮件 | 一次性覆盖核对补回，重启续跑，范围外不宣称修复 |
| 账户/凭据切换 | 恢复定时器等待时替换账户 | 旧 timer、ACK 和请求失效，新凭据恢复正确账户 |
| 凭据失效与限流 | 认证错误、Retry-After 分别注入 | 前者等待凭据，后者遵守期限，无登录风暴 |
| 用户可见刷新 | 点击刷新后延迟 provider，再提交 | 入队不显示完成；提交后列表/计数更新，后台保持静默 |

## Execution Boundaries

1. 本提案不授权运行任何测试、OpenSpec 校验、类型检查、构建、启动、重启或安装。
2. 用户明确要求验证后，可执行 `npm run verify:changed`；SQLite 测试使用兼容 Electron ABI 的运行时，禁止为测试覆盖生产 binding。
3. 真实互动验收使用隔离数据目录和测试邮箱，按授权操作进程；不自动停止当前共享客户端。
4. 单独记录运行的源码提交、构建、数据目录和产品版本。dev 验收不代表 `D:\Programs\WeMailClient\WeMail.exe` 已升级。
5. 保存计数、脱敏阶段时间和故障恢复轨迹；不把真实邮件正文、附件或凭据写入报告。
