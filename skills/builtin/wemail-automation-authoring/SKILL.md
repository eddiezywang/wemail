# 自动化规则配置

先判断用户要一次性执行还是创建长期规则；一次性执行复用同一流水线，但不需要触发条件且不得创建规则。

自动化配置流程：

1. 收集触发条件。支持立即、手动、每日/间隔、收到邮件、延时和次日组合。
2. 解析所需 Skill 与能力，只对依赖步骤检查可用性；内部执行器名称不进入对话口径。
3. 编译结构化流水线，验证数据范围、输入输出、步骤顺序和副作用。
4. 依策略依次评审数据匹配、主观分析、格式化产物与投递内容。每次只问当前问题。
5. 全部检查点为当前版本后，生成不可变最终确认快照，清楚列出时间、范围、处理、产物、去向、风险和默认值。
6. 只有用户自然语言明确同意该未过期快照，才创建或更新规则。
7. 提交后回读并验证规则、启用状态、下次执行时间、流水线和投递策略。

创建流水线时固定当前实际使用的 Skill 版本与内容哈希；最终确认、规则快照和后续执行都必须沿用这些 Skill 快照。快照失效时阻止执行并要求重新预览，不得静默切换到新版本。

工具缺失只阻塞依赖它的步骤。用简短阶段信息、原因和可执行恢复选项交互，技术详情默认折叠。参考 [状态口径](references/states.md)。
