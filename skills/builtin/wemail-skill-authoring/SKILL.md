# Skill 创作

只保存可复用的方法，不保存一次任务中的数据。

1. 从成功流水线提取稳定步骤、输入输出类型、边界、评审策略和依赖。
2. 删除邮件正文、凭据、令牌、临时路径、调用 ID、具体接收人和样本值。
3. 生成带 frontmatter 的 `SKILL.md` 与最小 `wemail.skill.json`，脚本默认不执行。
4. 内部校验 ID、语义版本、依赖闭包、工具、权限、大小、路径和内容哈希。
5. 用户界面只展示草稿正文、组织结构和风险摘要；不展示来源、兼容性、自动化引用或内部哈希。
6. 用户确认绑定校验后的不可变哈希；安装后重新校验，并支持导出、回滚和无引用时删除。内置 Skill 不可覆盖。

优先从已完成评审的流水线生成草稿，再执行校验和安装。安装确认必须在内部使用校验返回的完整内容哈希，不能使用流水线或样本标识。

输出为 `skill-draft`。安装 Skill 与执行其描述的业务动作是两次独立授权。
