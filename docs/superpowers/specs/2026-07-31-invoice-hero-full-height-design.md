# 首页发票动图全高布局修复设计

## 问题

首页发票动图的外层画布已改为 16:9，但内部工作区仍只有固定的 `31.4rem` 最小高度。在宽屏下，16:9 画布高于标题栏和工作区的合计高度，因此画布底部出现大片空白。

## 目标

- 保持首页动图外层宽度和 16:9 比例不变。
- 标题栏保持内容高度。
- 四列 App 工作区自动填满标题栏下方的全部剩余高度。
- 保持现有文字大小、四列宽度比例、动画流程和窄屏静态布局不变。

## 方案

将 `.invoice-hero__viewport` 设为两行 Grid 容器：第一行为标题栏的自然高度，第二行为 `1fr`。将 `.invoice-hero__workspace` 从固定最小高度改为可拉伸的 Grid 子项，使导航、邮件列表、阅读区和 AI 区域的背景完整铺到画布底部。

在 `max-width: 62rem` 的窄屏断点继续使用 `aspect-ratio: auto` 和既有最小高度，不改变移动端的两列/单列降级行为。

## 测试

- 先增加源码布局契约测试，要求宽屏 viewport 使用 `grid-template-rows: auto 1fr`，workspace 可填满第二行。
- 该测试必须在当前实现上失败，再实施 CSS 修复。
- 运行首页动图聚焦测试、网站完整测试、Astro 检查和生产构建。
- 通过 `http://127.0.0.1:4322/` 检查页面响应，并在浏览器预览最终效果。

## 非目标

- 不缩放整个模拟 App。
- 不增加邮件或 AI 内容填充空间。
- 不修改动画时序、控制器、16:9 宽高比或文档页动画。
