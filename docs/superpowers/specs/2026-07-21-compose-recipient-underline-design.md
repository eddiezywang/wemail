# 写信收件人下划线与主题占位文案调整设计

## 目标

让写信表单的可输入区域更容易识别，同时减少主题栏中不必要的提示文案：

- 主题输入框不显示 placeholder。
- 收件人、抄送和密送输入控件始终显示轻量下划线。
- 聚焦输入时通过下划线颜色变化提供明确但克制的反馈。

## 视觉方案

下划线绘制在整个 `DirectoryRecipientInput` 内容容器底部，而不是只绘制在内部文本输入框或整个 `RecipientRow` 上。

- 默认状态使用 1px `border-edge-3` 淡灰线。
- 控件内部任意输入框获得焦点时，下划线切换为 `border-coral`。
- 使用短时颜色过渡，避免突兀跳变。
- 不增加四周完整边框，保留当前轻微的聚焦底色。
- 下划线宽度覆盖联系人标签和剩余输入区域，但不包含左侧字段名称或右侧 CC/BCC 按钮。
- 联系人标签换行时，下划线始终位于整个控件的最底部。

## 主题输入框

移除主题输入框的“邮件主题” placeholder。由于可见的“主题”行标签没有与原生输入框建立 `label` 关联，输入框补充 `aria-label="主题"`，保证无 placeholder 时仍有可访问名称。

## 行为边界

本次只调整视觉提示与可访问名称，不改变以下行为：

- 企业通讯录 300ms 防抖检索。
- 中文输入法 composition 保护。
- 联系人候选、标签添加、删除和去重。
- 外部邮箱输入与批量粘贴。
- 收件人、抄送、密送和主题的序列化、草稿保存及发送校验。

## 测试与验收

- 主题输入框没有 placeholder，并具有“主题”可访问名称。
- 收件人控件的内容容器包含常驻底边线和聚焦底边线样式。
- 抄送和密送复用同一组件，因此获得一致样式。
- 现有通讯录搜索、候选选择、标签和输入法测试继续通过。
- TypeScript 类型检查和桌面 renderer 构建通过。
- 重启 WeMail 后，写信窗口中可看到淡灰下划线，聚焦时线条变为珊瑚色。
