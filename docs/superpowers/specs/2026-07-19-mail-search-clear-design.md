# 邮件搜索清除设计

## 目标

让用户点击搜索框中的 `×`、清空输入内容或按 Esc 后，退出搜索态并立即恢复当前邮件夹的无关键字列表。

## 交互

- 搜索词非空时显示显式的 `×` 清除按钮；其可访问名称为“清除搜索”。
- 点击 `×`、将输入删至空、或按 Esc，均调用同一退出搜索态路径。
- 退出搜索态删除 URL 的 `q` 参数，保留当前路径及现有分类/筛选参数；输入框仍获得焦点。
- 清除搜索不调用邮箱同步 API；路由改为普通列表查询，由 React Query 刷新当前文件夹的数据。

## 实现边界

仅修改 Workbench 的搜索工具栏和其组件测试。不会改变搜索请求、同步按钮、快捷键，或筛选器语义。

## 验收

1. 搜索后，点击可见的 `×`，地址与列表回到无 `q` 的当前收件箱。
2. `×` 在无关键字时不显示。
3. 清除操作不调用 `api.syncMail`。
4. Esc 的既有清除行为继续有效。
